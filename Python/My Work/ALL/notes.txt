jab bhi 2 list, dict ko aik sath traverse krna ho to zip function use kro:
        names = ["Ali", "Sara", "Ahmed"]
        scores = [85, 92, 78]

        for name, score in zip(names, scores):
            print(f"{name} score is {score}")

-> Note: Agar ek list doosri se bari ho, toh zip() choti list ke khatam hone par ruk jata hai. Unequal lists ke liye itertools.zip_longest() istemal kar saktay hain.



-> 2nd option:
range(len()) (Using Index)
Agar dono lists ki length barabar ho, toh index ke zariye access kar saktay hain.
        names = ["Ali", "Sara", "Ahmed"]
        scores = [85, 92, 78]

        for i in range(len(names)):
            print(f"{names[i]} score is {scores[i]}")
